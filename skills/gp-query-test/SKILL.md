## Порядок действий

1. Сохрани запрос в файл (не передавай многострочный SQL аргументом).
2. `python3 scripts/test_query.py <файл>.sql [alias]` — проверка через EXPLAIN.
3. Нужен результат — добавь `--run`: выполнит с лимитом 20 строк в
   read-only транзакции.
4. Ошибка — читай SQLSTATE и подсказку, правь запрос, повторяй.

## Правила

- Тестируй только читающие запросы. Скрипт откажет на DML, а сервер
  откажет ещё раз — не пытайся это обойти и не предлагай пользователю
  «просто выполнить напрямую».
- Изменение данных — не задача этого скила. Если пользователь просит
  проверить INSERT/UPDATE, объясни, что тестовый прогон невозможен, и
  предложи проверить вручную.
- Схему таблиц бери через `gp-table-ddl`, не угадывай колонки.
- `Broadcast Motion` или `Redistribute Motion` над большим набором —
  скажи об этом пользователю, это обычно узкое место.
